# Windows 外壳人工目视测试（S4–S20）

本文是给人看的**手工**验收清单。它和 `scripts/visual_check.py` 是两条互补的证据链：

| | `scripts/visual_check.py`（自动） | 本文（人工） |
| --- | --- | --- |
| 执行者 | 脚本：PostMessage 真 Win32 消息 + `PrintWindow` 抓像素 | 人：真的动手，真的看 |
| 覆盖 | 16 个场景 74 项像素/几何断言，落盘 51 张 PNG | 手感、光标形态、闪烁、拖拽跟随、菜单/对话框、跨 DPI |
| 局限 | 会抢前台（拖动类工具依赖 `SetCapture`），不模拟物理光标 | 慢，不可回归，单次结论 |

脚本能证明「消息进去、像素出来」，但**证明不了手感**。本清单里标 🤖 的条目脚本已覆盖（可以只看脚本产物复核），标 👁 的只能人工判断。

前置：

```
python scripts\build.py                # 引擎 + 553 用例 + 自检
python scripts\build_windows_shell.py  # 外壳 -> build\compositor_shell.exe
python scripts\visual_check.py         # 自动目视（可选，先跑它省手工）
```

建议环境：Windows 10/11，DPI 96 或 150 各跑一遍（跨 DPI 是脚本盲区），屏幕 ≥ 1440×900。
外壳客户区在本机为 1264×661（窗口外框 1280×720），画布矩形 x 248..934 / y 46..635，
空文档 1280×720 在「适合窗口」下缩放 49%，文档屏幕矩形约 (278,164)-(904,516)。
下列坐标只作参考，**以实际窗口为准**。

记录方式：每条填「通过 / 失败 / 不适用」，失败的写清现象 + 截图文件名。

## M1 启动与布局（S4/S5/S13）🤖

1. 启动 `build\compositor_shell.exe`，窗口标题应为 `Compositor (Windows shell)`，
   S13 之后带渲染后端后缀：`- CPU` / `- D3D12` / `- Vulkan` / `- Metal` / `- AUTO`。
2. 顶部工具栏 20 个工具按钮，顺序：A V M L P W C I B E J S R O G U T H Z Y。
3. 左侧图层面板（宽 248）、右侧属性面板（宽 330）、底部状态栏（高 26）都在，
   画布区域四周留白为应用底色 `(32,32,36)`。
4. 状态栏左侧是前景色块 + 十六进制值，右侧显示 `缩放 49%   笔刷 24 px / 75%   渲染 CPU`
   （或 `渲染 D3D12`）。
5. 窗口拉伸到很小（< 248+330+180）时右侧面板应先让位，画布不被挤成负宽。

👁 关注：启动瞬间有没有白屏闪烁；拉伸时状态栏文字有没有被裁掉。

## M2 画笔落色 + 撤销（S15 回归重点）🤖

> **这是 S15 修的真 bug**：`ReleaseCapture()` 会同步派发 `WM_CAPTURECHANGED`，
> 旧代码在把 `stroke_points` 搬出 `ShellState` **之前**就调用了它，处理器里的
> `stroke_cancel()` 把折点清空 —— 于是人手拖动画笔「看起来在画、松手什么都没有」。
> 自动化在旧版本上永远测不出来（脚本没走真 `SetCapture` 语义）。

1. 按 `B` 选画笔，`Shift+X` 输入 `FF8800` 回车（状态栏色块应变橙）。
2. 在画布上按住左键拖一条曲线，**松手**：应留下橙色笔迹，状态栏出现
   `画笔：已落色 N 个折点（#FF8800 · 直径 24 px）`。
3. `Ctrl+Z`：笔迹整体消失，状态栏 `撤销 1 / 重做 1` 之类计数变化。
4. `Ctrl+Y`：笔迹回来。
5. 换 `E` 橡皮擦，在笔迹上拖：松手后该处变透明（露出黑色文档底）。
6. `Ctrl+Z` 撤销橡皮擦，笔迹恢复。

👁 关注：笔迹是否**跟手**（不卡顿、不掉点）；松手瞬间有没有「闪一下才出来」；
快速甩笔时折线是否明显折角；光标是否画笔圈（若实现）。

## M3 Retouch：模糊 / 涂抹 / 液化（S9/S15 同步修复）🤖

1. 先用形状工具（`U`）铺一块色，按 `R` 进 Retouch，再按 `R` 循环 Blur → Smudge → Liquify
   （状态栏显示当前子模式）。
2. 在色块上拖动：松手后应看到模糊/拖拽/液化效果（同样受 S15 折点修复影响）。
3. `Alt+[` / `Alt+]` 调模糊半径或液化强度；强度调到 0 后拖动，像素**逐字节不变**。

## M4 吸管 / 前景色（S6）🤖

1. `I` 吸管，点画布任意有色像素：状态栏显示取到的 `#RRGGBB`，前景色块同步。
2. `Shift+X` 键入 `336699` 回车：色块变蓝灰；键入非法值（如 `GGGGGG`）应提示并保持原色。
3. `X` 在一组常用色之间循环切换。

## M5 选区：矩形 / 椭圆 / 套索 / 魔棒 / 钢笔（S4/S7/S8）🤖

1. `M` 矩形框选拖一个矩形：松手出现**蚂蚁线**（黑白交替虚线）。
2. `Ctrl+D` 取消选区：蚂蚁线消失。
3. 框选工具内再按 `M`：矩形 ↔ 椭圆循环（状态栏显示当前形状）；拖出椭圆时蚂蚁线是椭圆。
4. `L` 套索自由拖：松手闭合，蚂蚁线沿轨迹。
5. `W` 魔棒点色块：蚂蚁线沿颜色边界；`[` `]` 调容差（容差变大选区变大）；
   `Shift+W` 切「当前图层 / 合并图层」取样；`Alt+[` `]` 调取样窗口大小。
6. `P` 钢笔点若干锚点再回车：生成贝塞尔选区；点首锚点闭合；`Esc` 取消。
7. `Shift+F` 输入羽化半径（回车确认，`Esc` 取消）：之后新建的选区边缘发虚。
8. `Ctrl+A` 全选 / `Ctrl+Shift+I` 反选：蚂蚁线沿画布边缘 / 反向区域。
9. 已有选区时框选再加选（`Shift`）或减选（`Alt`）：蚂蚁线相应合并/挖掉。
10. 有选区时用画笔涂抹：只在选区内落色（选区裁剪生效）。

👁 关注：蚂蚁线是否**流动**（定时器动画）；快速拖动时选区是否跟手；
取消选区后有没有残留虚线。

## M6 渐变（S9）🤖

1. `G` 选渐变，`Shift+X` 设 `FF8800`。
2. 从画布左到右拖一条水平线，松手：左端接近 `#FF8800`，向右渐隐到透明/黑。
3. 反向拖（右到左）：方向相反。
4. 竖向拖：渐变方向变竖向。

👁 关注：拖动过程中有没有实时预览（还是松手才出）；渐变有没有色带。

## M7 形状（S10）🤖

1. `U` 形状工具，`Shift+X` 设 `3399FF`；再按 `U` 循环 矩形 → 椭圆 → 直线。
2. 拖一个矩形：内部填满前景色，外部仍是文档黑。
3. 再按 `U` 切椭圆，拖一个椭圆：中心填色，**包围盒四角不填**。
4. 拖拽时按住 `Shift`（正方/正圆）/ `Alt`（从中心）：形状符合修饰键语义。
5. `Alt+[` `]` 调线宽；`Ctrl+Z` 把形状逐个撤销掉。

👁 关注：拖动时有没有橡皮筋预览框；变形（宽高比）是否顺手。

## M8 文字 + 属性面板（S11/S14）🤖

1. `T` 选文字，右侧出现「文字（Type）」面板：Font Size / Line Height / Letter Spacing 三行，
   第一行高亮；面板底部有快捷键提示。
2. 在画布点一下：状态栏 `文字：插入点 (x, y)｜字号 32 px…`，画布上出现插入点/文本框预览。
3. 键入 `Hello`：画布预览随键入增长，状态栏显示行数与文本框尺寸。
4. `Shift+Enter` 换行；`Backspace` 删字符。
5. `Alt+]` 两次：行距 125% → 135%，面板与状态栏同步。
6. 点面板第一行（字号），键入 `48` 回车：面板 `Font Size = 48 px`。
7. 再点画布落第二个插入点，键入 `H` 回车提交：新字形明显比 32 px 的那个高。
8. 提交后状态栏 `文字：已应用（1 行）（撤销 N / 重做 0）`。
9. `Esc` 在键入态：丢弃缓冲，不产生撤销步。

👁 关注：插入点光标是否闪烁在正确位置；键入是否跟手（COM/输入法环境尤其）；
CJK 目前**不支持**（只收 ASCII），这是已知边界。

## M9 滤镜面板（S12/S13）🤖

1. 先铺满一块橙色（形状工具拖满画布）。
2. 菜单「滤镜」→ 选 Vignette（或按面板顺序切）：右侧出现滤镜面板，第一参数高亮。
3. 用 `=` / `-` 或数字键改 Amount：画布**实时**变暗四角、中心保持亮。
4. `Enter` 应用：状态栏 `Vignette：已应用`；`Esc` 关闭面板回到调整面板。
5. `,` / `.` 在 9 个滤镜间切换：依次经过 Vignette / Tonal Contrast / Bloom / Lens Correction /
   Gaussian Blur / Add Noise / Grain / Motion Blur / Progressive Blur，面板行数与第一行高亮随之变化。
6. Gaussian Blur：`Radius` 调到 8 左右回车：图像变糊；`Preserve 0/1` 设为 1 再应用：
   轮廓（透明边界）不扩散；`Ctrl+Z` **一次**回到应用前。
7. Add Noise：`Amount` 调到 40、`Seed` 改成 7 回车：画面加噪点；`Ctrl+Z` 撤销；
   再按同样参数应用一次，噪点图案应**逐像素相同**（同 seed 可复现）；改 `Seed` 后图案不同。
8. Grain：`Amount` 60、`Size` 1.5、`Roughness` 50 回车：出现颗粒；`Ctrl+Z` 一次回退。
   把 `Amount` 调回 0 回车：状态栏提示恒等、不产生撤销步。
9. Motion Blur：先画一个**边缘清晰的小方块**（形状工具拖一小块）。`Distance` 设 30、
   `Angle` 0 回车：方块沿水平方向拉出条纹，上下远端不糊；`Angle` 90 再应用：
   条纹转成竖直。`Ctrl+Z` **一次**回到应用前；`Distance` 保持 0 时回车
   应报恒等、不产生撤销步。输入 `0.5` 回车会被拒绝（量程是 0 或 1..2000）。
10. Progressive Blur：先铺一块**高频纹理**（Gaussian Blur 那段的小方块也可）。
   `From` 0、`To` 40 回车：默认轴（图层中线、自顶向下）上端锐、下端糊。
   再打开面板，在画布上**从左上向右下拖一条线**：拖拽中画实线、松手后画虚线，
   状态栏显示两端坐标；`Radial 0/1` 设为 1 时轴变成以起点为心的径向渐变
   （角上最糊、中心不糊）；`Inverted 0/1` 设为 1 交换两端。回车应用，
   `Ctrl+Z` **一次**回到应用前。拖轴本身不产生撤销步；`Ctrl+N` 新建文档后旧轴作废。

👁 关注：实时预览的帧率是否可接受（CPU 全幅重算，大图会慢）；面板参数多时是否滚动。

## M10 调整层（S12/S14/S15）🤖

> **用法要点**：调整是「调整图层」，只作用于**它下方**的内容。挂在有像素的图层上
> 看不到变化是符合上游语义的（`EditorCanvas.swift:3092`），不是 bug。

1. 铺一块色（形状工具拖满）。
2. `Ctrl+Shift+N` 新建一层（新层在最上面并被选中）。
3. `Ctrl+Shift+A` 新增 Exposure：面板显示 `类型 4/12：Exposure`、三个参数、
   `该图层已有调整：1`，底部提示「调整只作用于下方 · 挂在新图层上」。
4. 按 `=` 六次把 Exposure 抬到 2 左右，`Ctrl+Shift+U` 应用：
   下方像素**明显变亮**，状态栏 `已应用调整 Exposure`。
5. `Ctrl+Z` 撤销：亮度回到应用前。
6. `,` / `.` 在多个已有调整间选择；`Ctrl+Shift+D` 删除选中调整。

👁 关注：参数连续调时画面是否实时更新；应用后有无一帧闪烁。

## M11 图层（S5/S14/P0-1）🤖

1. `Ctrl+Shift+N` 连按两次：图层面板出现 3 行，选中行高亮。
2. `Ctrl+Shift+V` 切换可见：该层缩略/文字变暗，画布上该层内容消失。
3. `Ctrl+[` / `Ctrl+]` 调不透明度 100% → 90% → …，画布可见变化。
4. `Ctrl+E` 向下合并：图层数减少，画面不变。
5. `Ctrl+Z` 撤销合并。
6. **P0-1 验收路径（每条命令后按一次 `Ctrl+Z`，必须恰好退回上一步，不许多退/少退）**：
   ① 点第 1 行 → Ctrl 点第 2 行（两行同时高亮）→ `Ctrl+G` 建组：出现组行 + 两个子层；
      **组内上下顺序与建组前一致**（选中的上层仍在上面）。
   ② 把根级最底层拖到**组行中间带**：该层进入组、落在组顶；拖回根级行 = 移出组。
   ③ 选中组 → `F2` → 输入「组甲」（中文应能直接键入）→ 回车：组行名字变成中文。
   ④ `Ctrl+J` 复制：多一行副本，画布不变。
   ⑤ `Shift+O` → 输入 `37` → 回车：行尾显示 37%，画布半透明。
   ⑥ `Del` 删除：行消失；多选时整批一起删。
7. `Ctrl+Y` 重做应与撤销前逐项一致（建组/复制/改不透明度/删除各一次）。

👁 关注：点击图层行切换选中是否跟手；缩略图（若实现）是否随编辑刷新；
**Ctrl+G 后画面是否上下颠倒**（P0-1 修过 `move_layer` 末尾落位缺陷，这是回归重点）；
组行显示在子层下方是已知偏差（引擎落位口径，非本轮引入）。

## M12 视图（S4）🤖

1. `Ctrl+0` 适合窗口：文档完整可见、四周留白，状态栏 `适合窗口：49%`。
2. `Ctrl+=` 两次放大：文档吃掉留白、出现裁切；`Ctrl+-` 缩小回去。
3. `Ctrl+1` 实际像素（100%）：画布被文档覆盖。
4. `H` 抓手拖动 / 按住空格拖动 / 中键拖动：平移视图（不改变文档像素）。
5. 菜单「视图」里放大/缩小/适合/实际像素逐项可用。
6. 按 `Z`：工具栏第 19 个按钮（Z）高亮，状态栏
   `工具：Zoom（点击放大 1.2 倍 / 拖框放大到该区域；Alt+点击缩小；双击画布 = 100%；Ctrl+0 适合窗口 / Ctrl+1 实际像素）`。
7. 在画布某处连点 3 次：每次放大 1.2 倍（状态栏 `缩放 144%（放大·以点击点为锚）` 之类），
   **点击点下方的像素始终不动**（用一个小方块当参照）；`Alt+点击` 逐步缩回。
   全程文档像素不变、撤销计数不变。
8. 一路放大到 3200%：状态栏 `缩放 3200%：已到上限 3200%，画面不再变化（Ctrl+0 适合窗口）`，
   画面不再位移；反向缩到 2% 同样写「已到下限」。
   选中 `Z` 时按住空格拖动：仍是**抓手平移**（临时抓手优先于 Z）。
9. `Ctrl+0` 后按住 `Z` 在画布上拖出一个约 1/4 画布的矩形：拖动中显示白实线 + 黑虚线框；
   松手后该区域铺满画布，状态栏 `缩放 NNN%（框选放大：拖出的区域铺满画布；Ctrl+0 适合窗口）`，
   区域中心落在画布中心（拖左上角与拖右下角各试一次）。
10. 用 `Z` 按下后位移不到 4 px 就松手（或直接单击）：仍按单击放大 1.2 倍处理
    （`缩放 NNN%（放大·以点击点为锚）`），不会把视图缩放到一个针尖大的区域。
11. `Z` 双击画布：状态栏 `缩放 100%（实际像素）：双击画布；Ctrl+0 适合窗口`。
    净结果是 100%，不应停在 120% / 144% 之类（第一次点击的 1.2 倍会被双击复位）。
12. 光标形态：`Z` 在画布内显示放大镜（玻璃内十字），按住 `Alt` 变成横线（缩小形态）；
    移到图层面板/工具条恢复默认箭头；按住空格平移时是抓手，松开回放大镜。
13. 夹取：缩到 2% 后拖一个很大的框 → 放大但矩形仍居中；到 3200% 后再拖框/单击，
    状态栏写「已到上限」，画面不再变化。

👁 关注：缩放时像素是否**清晰**（无插值糊）；平移是否跟手；光标形态变化；
连点时锚点是否稳定（若目标像素每次偏一点，说明没用点击点当锚）；
拖框矩形是否跟手、松手后区域中心是否真的落在画布中心；
自绘放大镜在深色/浅色画面上是否都看得清（单色反色设计，必要时放大系统光标尺寸再试）。

## M14 GPU 渲染后端（S13/S16/S19/S20）👁

> **交互外壳的主画布始终是 CPU 展平 + GDI**（面板、蚂蚁线、笔迹预览都是 GDI 覆盖层，
> 不能与直呈安全混用）。所以 M14 分两部分：能力/标题看外壳，真正的 GPU 上屏看
> `--present-bench` 独立窗口。

1. `python scripts\build.py --gpu` 后再 `python scripts\build_windows_shell.py --gpu`，
   启动外壳，标题后缀应为 `- D3D12`（驱动/调试层不可用时回落 `- CPU`），状态栏 `渲染 D3D12`。
2. 在主画布画几笔、加组/蒙版/调整层：**画面必须与 CPU 构建逐像素一致**，不花屏、不报错
   （主画布本就是 CPU 路径；GPU 相关正确性由 `--gpu` 的 553 例用例与对拍守住）。

## M18 调整滑杆 + 曲线/色阶编辑器（P0-3）🤖

> 前置同 M10：先铺一块色（`U` 拖满画布），`Ctrl+Shift+N` 新建一层，再 `Ctrl+Shift+A` 新增 Exposure。

1. 在参数行的**滑道**上按下并左右拖：数值跟手变、画布**实时**变亮/变暗，状态栏

2. 松手：状态栏 `已应用 … （一步撤销）`；`Ctrl+Z` **一次**应回到拖动前

5. 还没 `Ctrl+Shift+U` 的新增态下拖滑杆：只显示 `预览值，Ctrl+Shift+U 应用`，
   `Ctrl+Z` 不应撤销这些预览值。
6. `,` 退一档到 `类型 3/12：Curves`（状态栏报当前种类），`Ctrl+Shift+A` 新增一条恒等曲线：
   参数区出现**正方形**绘图区 + `RGB / R / G / B` 通道条。
7. 在绘图区中间略下方按下并往上拖：曲线上出现一个中段控制点并被抬起，画布**实时**变亮。
8. 松手后按一次 `Ctrl+Z`：曲线回到恒等（一次拖动 = 一步撤销）。
9. 拖两个端点：x 不动、只有 y 变（端点锁 x = 0 / 255）；拖内部点往左越过左邻点：
   被夹住不交叉，且 x 严格递增。
10. 点一下某个内部点让它成为焦点，按 `Delete`：该点消失、曲线随之变；连续删到只剩两点时
    提示「曲线端点不能删除」。
11. 点通道条 `R`：曲线换成 R 通道（空 = 恒等）；在 R 通道上抬中间调：画面**偏红**，

12. `,` 再退一档到 `类型 2/12：Levels`，`Ctrl+Shift+A` 新增色阶：参数区出现通道条 +
    20 个参数行（窗口矮时可滚）。把第一行 `RGB Black` 的滑杆拖到 ~40：暗部明显压死。
13. 一次 `Ctrl+Z` 回到色阶修改前。
14. `Ctrl+S` 存成 `.comp`，`Ctrl+O` 打开：曲线点位落在原处、色阶数值原样；
    再拖一次曲线点后 `Ctrl+Z`，仍只退一步。

👁 关注：拖动是否跟手（不卡、不跳、不丢步）；松手瞬间画面有无「闪一下才出来」；
曲线插值有没有不该出现的过冲/波纹；控制点好不好点中（命中半径 7 px）；
150% DPI 下绘图区与滑道是否仍对齐；色阶 20 行滚动时高亮行是否滚进可视区。

## M21 路径面板（P0-4 可选）👁

> 路径在本壳里只是「已提交钢笔路径的锚点副本」，唯一用途是重新落成选区；
> 引擎没有路径实体，所以它**不随 `.comp` 保存**（见 shell-parity §5.17）。

1. 按 `P` 选钢笔，在画布点 4 个锚点，`回车` 提交：状态栏
   `钢笔：已应用闭合选区；路径已入列 路径 1（双击路径面板可再落一次）`。
2. `Ctrl+Shift+P`（或「选择 → 路径面板…」）：右侧出现「路径（Paths）」，
   摘要 `已存 1 / 64 条`，一行 `1. 路径 1 · 4 个锚点`，首行高亮。
3. 再画一条 3 锚点路径 `回车`：列表变两行，新行自动高亮并滚进可视区。
4. `Ctrl+Z` 一次：只撤掉刚才那次选区，**路径行仍在**（入列不产生撤销步）。
5. `↑` / `↓` 选行：高亮跟着走，状态栏报 `路径 N/2：…（M 个锚点）`；选到看不见的行时
   列表自动滚动。
6. 选中第 1 行按 `回车`：状态栏 `路径「路径 1」已转成选区（一步撤销）`，蚂蚁线沿那条路径；
   `Ctrl+Z` **一次**回到转之前的选区。
7. 在列表里**双击**某一行：与回车等价（同样一步撤销、同样状态栏）。
8. `Del` 删除选中行：行消失，状态栏 `已删除路径「…」（剩 N 条，选区不动）`；
   **不能** `Ctrl+Z` 把它撤回来（列表不在文档历史里）。
9. `Esc` 关面板；再开一次，列表内容仍在（同一文档内）。
10. 面板开着时按 `B` 等工具字母键：无反应（面板拥有键盘）；只有 `Ctrl+…` 快捷键穿透。
    同理 `Del` 删的是**路径行**，不会删图层。
11. 钢笔落点中（先 `Esc` 关面板 → 按 `P` → 再 `Ctrl+Shift+P` 开面板 → 画布点几个锚点）：
    `回车` 提交的是**当前钢笔路径**（新路径入列），不是「应用选中路径」；
    `Esc` 取消当前这条钢笔路径、面板不关。
12. 切到 `T` 文字工具：右栏换成文字属性面板，状态栏提示
    `路径面板已打开（T 文字工具占着右栏，切走后可见）`；切回别的工具面板恢复。
13. 面板开着时去开「色彩范围…」或滤镜/效果面板：路径面板让位；
    反过来开路径面板也会关掉它们。
14. `Ctrl+N` 新建文档：路径列表清空（锚点是旧文档坐标）。
15. 建 64 条以后再来一条：状态栏出现 `（到 64 条上限，最旧一条被挤掉）`，列表仍是 64 行。

👁 关注：列表滚动后单击行是否命中**看得见的那一行**（不要点第 0 行却选到第 5 条）；
双击是否偶尔被当成两次单击（高亮跳一下但没转选区）；空白处点击不应改选区、不应落笔；
面板很矮（把窗口拉窄拉矮）时行数与滚动是否合理，底部三行提示有没有被裁掉。

## M22 历史记录面板（P1）👁

> 面板列的是**状态**：第 0 行 = 文档最初状态，第 i 行 = 第 i 步之后的状态。
> 高亮行就是引擎的当前下标（`undo_depth`），不是壳侧另存的一份指针（见 shell-parity §5.18）。

1. 新建文档，做三件事（例如：新建图层 → 用画笔涂一笔 → 改不透明度），每步各算一步撤销。
2. `Ctrl+Alt+H`（或「编辑 → 历史记录…」）：右侧出现「历史（History）」，
   摘要 `4 个状态 · 当前第 4 个`，列出 `0. 最初状态（新建 / 打开）` 起共 4 行，末行高亮。
3. `Ctrl+Z` 两次：高亮**跟着上移**两行（不是面板自己改），末两行变成暗色（在重做侧）。
4. 点第 1 行：立刻回跳到「第 1 步之后」的状态，画布/图层/选区一起回退，状态栏
   `已回跳到第 2/4 个状态：…`；再点第 3 行：直接前进，**不需要**中间那步。
5. 点当前行（高亮那一行）：状态栏 `已在该状态（未改动，不产生撤销步）`，画面不动。
6. `↑` / `↓` 各按几次：一次一格，到顶/到底停住；`Home` / `End` 回跳最前 / 最后。
7. 回跳几次之后看撤销栈：`Ctrl+Z` 仍然只撤「一步」，面板行数**没有变多**
   （回跳不新增历史记录）。
8. 在回跳后的中间位置做一次新编辑：当前行之后的行**消失**（重做链被丢弃），列表变短。
9. 图层/选区跟着走：回跳到很早的状态时，图层面板与蚂蚁线一起变；
   `Ctrl+Z` / `Ctrl+Y` 与点行的结果一致（同一条撤销栈）。
10. 面板开着时按 `B` 等工具字母键：无反应（面板拥有键盘）；只有 `Ctrl+…` 快捷键穿透。
11. 钢笔落点中（`Esc` 关面板 → 按 `P` → 点几个锚点 → `Ctrl+Alt+H` 开面板）：
    `回车` 提交的是**当前钢笔路径**、`Esc` 取消当前路径，面板都不关。
12. 切到 `T` 文字工具：右栏换成文字属性面板，状态栏提示
    `历史记录面板已打开（T 文字工具占着右栏，切走后可见）`；切回别的工具面板恢复。
13. 面板开着时去开「路径面板…」「色彩范围…」或滤镜/效果面板：历史面板让位；
    反过来开历史面板也会关掉它们（色彩范围的预览事务先被 abort）。
14. `Ctrl+N` 新建文档：列表回到 1 行（`0. 最初状态`），滚动归零。
15. 把窗口拉得很矮：可见行数变少，滚轮一格 3 行，底部三行提示仍在、不裁字。

👁 关注：滚动后单击是否命中**看得见的那一行**（不要点第 0 行却跳到第 5 个状态）；
回跳后高亮与画面是否同一瞬间跟手（有无一帧旧画面）；撤销/重做与点行混用时高亮
有没有跳到不存在的行；暗色行（重做侧）在深色背景上是否够看得清。

## M23 减淡 / 加深 / 海绵（P1）👁

> Burn/Highlights → Sponge/Desaturate → Sponge/Saturate`（再按回到第一档）。
> 从别的工具切进来一律落在 Dodge/Midtones。

1. 新建文档 → 新建图层 → 铺一块**中灰**（例如用色彩范围/填充得到 128 灰）。
   选一个能看见颜色的 8 位图层。
2. 按 `O`：工具栏第 14 个按钮（O）高亮，状态栏左上出现当前档名
   `Dodge / Midtones` 与 `强度 …%`；工具栏右侧也显示同一组文字。
3. 在灰块上拖一笔：笔迹所过之处**变亮**（中间调），松手后画面保持；
   状态栏显示 `Dodge / Midtones：已应用 N 个折点（强度 50%）`。
4. `Ctrl+Z` **一次**：整笔回退（不是逐折点回退）；再 `Ctrl+Y` 恢复。
5. 连按 `O` 到 `Burn / Midtones`，在同一块灰上拖一笔：笔迹处**变暗**。
6. 切到 `Dodge / Shadows` 再在**亮部**拖：变化应明显小于中间调（Range 权重）；
   切到 `Dodge / Highights` 在暗部拖：几乎不变。
7. 切到 `Sponge / Desaturate`，在一张彩色图上拖：笔迹处颜色变灰、亮度基本不变；
   再切 `Sponge / Saturate`：颜色更艳、不会溢出成奇怪的色块。
8. 在**纯灰**上用 `Sponge / Saturate` 拖一笔：画面**逐字节不变**，状态栏带引擎 note
   `tone stroke changed no pixel (arithmetically a no-op)`，且 **`Ctrl+Z` 不会撤出一步
   空操作**（撤销的是上一笔）。
9. 笔尖落在**图层外**（例如图层只占画布一角，在空白区域拖）：
   状态栏说笔迹与图层不相交，撤销栈不变。
10. `Alt+[` / `Alt+]`：强度每次 10%，到 1% / 100% 停住；状态栏数字立即更新，
    下一笔按新强度算（已落下的笔迹不回溯）。
11. 选区约束：用矩形选区框住左半 `Ctrl+A` 之类任意选区 → 拖一笔横跨选区边界：
    选区外（含选区内但笔尖未覆盖处）**逐字节不变**；取消选区（`Ctrl+D`）后再拖整笔生效。
12. 16 位图层（若有）：三种工具在笔迹之外**保持 16 位**（状态栏格式不变），
    笔迹内也仍是 16 位——与画笔同口径，不是先降到 8 位再补。
13. 不选图层直接拖：状态栏提示「请先选择一个图层」，不产生撤销步。

👁 关注：重复按 `O` 时档名是否与画面实际效果一致（状态栏说是阴影就真的按阴影算）；
笔迹边缘是否出现台阶（Range 权重已走 smoothstep）；`Alt+[ / ]` 在中文输入法下是否被吞；
减淡到接近纯白 / 加深到接近纯黑时有没有卡住不动（那是数学上的 no-op，属预期）。

## M24 历史记录画笔（P1）👁

> `Y` 键进 History Brush。默认取样 = **当前状态的上一格**（「往回刷一步」）；
> `Shift+点历史面板的行` 显式把某一格指定为取样源，**当前画面不回跳**。
> 每一笔（松手）= **恰好一个撤销步**。

1. 新建文档 → 新建图层 → 用画笔画一块红色。打开历史面板（`编辑 → 历史记录…`，
   或直接按 `Y`：切到历史记录画笔会自动打开面板）。
2. 按 `Y`：工具栏第 20 个按钮（Y）高亮，历史面板里某一行显示 `← 画笔取样`；
   状态栏写 `工具：History Brush（Y）· 取样第 N 个状态`，工具栏右侧与状态栏
   都显示 `不透明度 100%`。
3. 在红色块上拖一笔：画面**回到上一步的样子**（最后一笔被刷掉），笔迹边缘有
   圆形羽化；状态栏显示 `历史记录画笔：取样第 N 个状态，已应用 M 个折点`。
4. `Ctrl+Z` **一次**：整笔回退（回到用画笔涂过的样子）；再 `Ctrl+Y` 恢复。
5. `Shift+点`历史面板第 0 行（最初状态）：该行变成 `← 画笔取样`，但**画面不变**
   （不会跳回最初状态）。此时在画布上拖：被刷到的区域回到「最初状态」的样子。
6. 普通**单击**历史面板某行（不按 Shift）：画面回跳到该行（与 M22 相同），
   取样标记仍留在原来那一行——回跳与取样是两件事。
7. `Alt+[` / `Alt+]`：不透明度每次 10%，到 10% / 100% 停住（0 会被引擎拒绝，
   所以键盘下限就停在 10%）。降到 50% 再拖：只恢复一半，颜色是当前与取样状态的混合。
8. 选区约束：`Ctrl+A` 之类任意选区 → 拖一笔横跨选区边界：选区外逐字节不变。
9. 16 位图层（若有）：笔迹之外保持 16 位，撤销后逐字节复原（不是先降 8 位再补）。
10. 选一个「在该取样状态下还不存在」的图层（先加图层再取样到更早的状态）后拖笔：
    状态栏提示「历史记录画笔失败：取样第 N 个状态（该状态下可能没有此图层）」，
    不产生撤销步、像素不变。
11. 取样状态与当前像素**完全相同**时拖笔：状态栏带引擎 note
    `history brush changed no pixel`，`Ctrl+Z` 不会撤出一步空操作。

👁 关注：`← 画笔取样` 标记是否只在 Shift+点行之后出现、普通点行回跳后标记是否
留在原地；按 `Y` 自动打开面板时右栏是否被别的面板（滤镜/色彩范围/路径）让位；
`Alt+[ / ]` 在中文输入法下是否被吞；笔刷直径/硬度是否与画笔共用（`[` `]` 有效）。

## M25 图像菜单：转画布 / 修边 / 反相（2026-10-21）

> 三条命令的引擎实现早已存在，本轮补的是壳侧产品通路。旋转与修边**都不重采样**：
> 画布换尺寸、图层换落位，像素字节不动（画布外内容还在，裁回来会露出来）。

1. `Ctrl+N` 新建（1280×720），用 `U` 形状工具在画布**左下角**拖一个小方块。
2. 菜单「图像 → 图像旋转 → 顺时针 90°」：画布变成 720×1280（适合窗口比例随之变化），
   方块转到**左上角**；状态栏 `已旋转画布：顺时针 90°（撤销 N / 重做 0）`。
3. `Ctrl+Z` **一次**：回到 1280×720，方块回左下角（不许多退/少退）。
4. 再选「逆时针 90°」两次：结果应与直接选「180°」一次逐像素一致（方向相反）；
   三种旋转都不应出现插值糊边（只改落位，不重采样）。
5. 空文档：新建后立刻「180°」→ 状态栏 `画布未变化（空文档且旋转后尺寸不变，未产生撤销步）`，
   撤销计数不动。
6. 修边前置：新建 → 画一个小方块（四周是透明的）。菜单「图像 → 修边…」：
   右栏出现「修边（Trim）」，六行 Based On / Top / Bottom / Left / Right / Tolerance，
   首行高亮，状态栏 `修边：Tab 选行 · -/= 调值 · 回车应用 · Esc 关闭（撤销一步）`。
7. `Tab` / `Shift+Tab` 逐行移动（到顶/到底停住），状态栏 `修边 N/6：<行名>`；
   在 `Based On` 上按 `-` / `=` 循环 Transparent Pixels / Top Left Pixel Color /
   Bottom Right Pixel Color，在四条边行上按 `-` / `=` 切换 on / off。
8. 默认（Transparent Pixels · 四边 on）按 `回车`：画布裁到小方块的包围盒，
   视图重新适合窗口；状态栏 `已修边（基于 Transparent Pixels · 容差 0）（撤销 N / 重做 0）`。
   `Ctrl+Z` **一次**回原尺寸。
9. 基于颜色：`Tab` 回 `Based On` 切到 Top Left Pixel Color，数字键输入 `10` 回车
   （面板 `Tolerance = 10`，键入态 `Backspace` 删字符、`Esc` 取消），再回车应用：
   与左上角色**逐通道差 ≤ 10** 的边缘一起被裁掉；`Ctrl+Z` 一次回原。
10. 四边全关（在四条边行各按一次）后回车：状态栏 `修边：至少勾选一条边（当前四条边都关）`，
    面板留着、无撤销步。`Esc` 关面板：画布不变、无撤销步。
11. 反相：选中一个**有像素**的图层，`Ctrl+I`（或菜单「图像 → 反相」）：
    颜色反相（例如橙 → 蓝），**透明区域保持透明**；状态栏 `已反相图层（撤销 N / 重做 0）`；
    `Ctrl+Z` 一次恢复。`Ctrl+Shift+I` 仍是**反选**，两条快捷键不要混。
12. 有选区时反相：只在选区内变化（选区外逐字节不变）；先把选区收缩到空再反相 →
    状态栏 `反相：选区为空，未改动`，无撤销步。
13. 组图层 / 空图层反相：状态栏 `反相：组图层或没有像素的图层（未改动）`；
    HDR（RGBA16F）图层（若有）：`反相：HDR（RGBA16F）图层不受支持（未改动）`。
14. 面板互斥：修边面板开着时打开滤镜 / 效果 / 色彩范围 / 路径 / 历史任一面板 →
    修边让位；反过来开修边也会关掉它们。修边面板开着时按 `B` / `U` 等工具字母键无反应
    （面板拥有键盘），只有 `Ctrl+…` 穿透。
15. 旋转时修边面板若开着：应先被收掉（四条边是按旧画布算的），不留在屏幕上。

👁 关注：旋转后画面是否**像素清晰**（无重采样糊边）、图层位置是否吻合；
蚂蚁线/选区是否随画布一起转置；修边后状态栏与画布尺寸是否一致；
反相是否严格遵守选区边界（边缘无半像素色带）；150% DPI 下六行文字是否重叠。

## M26 仿制图章（S）（2026-10-21）

> 仿制图章是**两段式**的：源点由壳保存（Alt+点击落点），引擎只负责按偏移采样。
> 首笔的偏移 = `round(源点 - 首个折点)`，由引擎现算、壳用同一组整数记住；
> 之后每一笔都复用这组偏移 —— 所以松开鼠标再拖，笔迹与源点的相对位置不变。
> 每一笔（松手）= **恰好一个撤销步**。

1. 新建文档（1280×720），在**左下角**用 `U` 画一个红方块，在**右上角**画一个蓝方块。
   新建图层（仿制会写到当前图层，方便看结果）。
2. 按 `S`：工具栏第 12 个按钮（S）高亮；状态栏
   `工具：Clone Stamp（S）· 先 Alt+点击画布设置源点（Shift+Alt = 整篇合成）；Shift+K 切取样范围（当前图层），Shift+S 切对齐（开），Alt+[ / ] 调不透明度（100%）`，
   工具栏右侧显示 `未设源点`。
3. 不设源点直接在画布上拖一笔：状态栏
   `仿制图章：先 Alt+点击画布设置源点（Shift+Alt = 整篇合成，Shift+K 切取样范围）`，
   画面像素不变、撤销计数不动。
4. `Alt+点击`红方块中心：**不落笔**（红方块不变、无撤销步），画布上出现
   **源点十字**（黑实线圆 + 白点线圆 + 20px 十字）；状态栏
   `仿制图章：源点 (x, y)｜当前图层取样｜拖动开始仿制`，工具栏右侧变为 `源 x,y图层`。
5. 在蓝方块旁边拖一笔：落笔处出现**红方块的图案**（不是蓝的）；状态栏
   `仿制图章：已应用 N 个折点（源 (x, y) · 当前图层 · 直径 M px）`，
   `Ctrl+Z` **一次**整笔回退，`Ctrl+Y` 恢复。
6. **对齐**：松开鼠标后再在别处拖第二笔：新笔迹的采样点与第一笔**平行同位**
   （即源点 + 同样的相对位移），不会跳回源点重新开始。
7. 缩放/平移画布（`Ctrl+=` / 空格拖 / 滚轮）后：源点十字**跟着画布走**，
   始终钉在同一个文档像素上；此时拖笔，采样位置仍与十字一致（不因缩放偏移）。
8. `Shift+Alt+点击`：源点十字照常出现，状态栏写成 `整篇合成取样`，工具栏显示 `合并`。
   在「只有红方块、当前图层是空图层」的情况下拖笔：仍能刷出红方块（说明取的是合成结果，
   而不是空图层）；此时 `Ctrl+Z` 一次整笔回退。注意这不是一次性覆盖：选项被置成
   `合并` 并**保持**，之后不带 Shift 的 `Alt+点击` 换源点仍是 `合并`（见步 18）。
9. 源点落在**画布外**（缩小画面后点空白区域）：状态栏 `仿制图章：源点必须在画布内`，
   不设源点、不产生十字。
10. 新建文档 / 打开图片 / `Ctrl+O` 换文档：源点自动作废（工具栏回到 `未设源点`），
    此时拖笔会提示 `仿制图章：先 Alt+点击画布设置源点…`，不会拿旧文档的坐标去采样。
11. 有选区时拖笔：只在选区内落笔，选区外逐字节不变（选区约束与其他画笔一致）。
12. 选中一个**组图层**或**没有像素的空图层**（引擎先拦组、再拦空，若无则跳过）：
    拖笔后状态栏 `仿制图章失败（错误码 N）`，像素不变、不产生撤销步。
13. 重新按 `S`：状态栏在原有提示后多了 `Shift+K 切取样范围（当前图层），Shift+S 切对齐（开），Alt+[ / ] 调不透明度（100%）`。
14. `Alt+[` 按到 `仿制不透明度 30%（对齐）`：在空白处拖一笔，落笔**明显变淡**
    （仍能看到源图案，但只盖住三成）；`Ctrl+Z` 一次整笔回退。
15. 按 `Shift+S`：状态栏 `仿制对齐：关（每一笔都以源点重新对位；Shift+S 切换）`。
    在 A 处拖一笔、再在 B 处拖一笔：两笔的图案都**以笔迹起点对齐到源点**
    （即第二笔不会延续第一笔的偏移，而是重新以源点为基准）。
16. 再按 `Shift+S` 回到 `仿制对齐：开（…）`，在 C 处拖一笔：这一笔重新建立偏移
    （不会跳回第 15 步之前的旧位置），落笔文案显示 `对齐 · 不透明度 N%`；
    再在 D 处拖第二笔：偏移与 C 平行同位。
17. 新建文档 / `Ctrl+O` 换图片：源点作废（`未设源点`），但**不透明度与对齐开关保持**
    （例如仍显示 `仿制不透明度 30%（对齐）`），重新设源点后按当前选项落笔。
    取样范围则是例外，会随源点一起回到 `当前图层`（见步 21）。
18. 按 `Shift+K`：状态栏 `仿制取样：整篇合成（Shift+K 切回当前图层）`，
    **不产生撤销步**（历史面板计数不变、画布不变——这是选项不是操作）。
19. 普通 `Alt+点击` 换一个源点（不按 Shift）：状态栏仍是 `整篇合成取样`，工具栏仍是 `合并`
    ——选项没有被换源点冲掉。在「当前图层是空图层」时拖一笔：能刷出下层图案。
20. 再按 `Shift+K`：`仿制取样：当前图层（Shift+K 切到整篇合成）`；普通 `Alt+点击` 设源点后
    拖笔：状态栏 `当前图层取样`，空图层上拖笔**不会**刷出下层内容（只取本层）。
21. 按 `Shift+K` 切到 `整篇合成` 后再 `Shift+Alt+点击`：状态栏仍写 `整篇合成取样`（幂等，
    不会翻回去）；随后 `Ctrl+O` 换图片：取样范围回到 `当前图层`（与不透明度/对齐的行为不同，
    因为它跟着源点走）。

👁 关注：`Alt+点击` 是否被菜单栏抢走（松开 Alt 后不应弹出「图像」菜单）；
源点十字在 150% DPI 下是否位置准确、线宽是否与画布 1px 对齐；
首笔与第二笔的采样错位是否**完全一致**（若第二笔整体偏半像素，说明壳侧偏移没按
`round` 取整）；仿制边缘是否有圆形羽化（硬度应与画笔共用 `[` `]` 设置）。

## M27 Move 工具拖拽图层（V）（2026-10-21）

> Move 工具现在按**有没有选区**分流：有选区 → 只搬选区内的像素（老路径）；
> 没有选区 → 拖的是**整层的 transform.origin**，像素不动、旋转不变。
> 一次拖动（按下到松开）= **恰好一个撤销步**；拖动中实时看到结果，不是虚线预览。

1. 新建文档（1280×720），`U` 画一个红方块（背景层），新建图层再画一个蓝方块（图层 1），
   在层面板里选中**图层 1**。
2. 按 `V`：工具栏第 2 个按钮（V）高亮，状态栏
   `工具：Move（V）· 无选区 = 拖整层、Alt+拖动 = 复制一份再移动；有选区 = 搬选区像素（Alt = 复制）；方向键微调 1 px（Shift 1 / Ctrl 10）`。
3. 在蓝方块上按住左键拖到别处：蓝方块**跟着鼠标实时移动**，红方块不动；
   拖动中状态栏 `移动图层：(x, y)，位移 (dx, dy)（松开算一步撤销）`。
4. 松开：状态栏 `已移动图层：位移 (dx, dy)（一步撤销）（撤销 N / 重做 0 · 历史 … KiB）`；
   撤销计数**只加 1**（拖多远都只加 1）。`Ctrl+Z` 一次整体回到原位，`Ctrl+Y` 回到新位置。
5. 点一下画布但**不移动**就松开：状态栏 `移动：位置未变化`，撤销计数**不变**（不留空步）。
6. 快速来回拖：拖出 100 px 再拖回原处松开，图层**精确回到**按下时的位置
   （位移由基准矩形 + 取整推导，不在上一帧上累加，所以不会越拖越漂）；
   反复拖出/拖回 10 次后位置仍与开始完全一致（若每次偏 1 px，说明用了累加写法）。
7. 拖动过程中按 `Esc`：图层**弹回**按下时的位置，状态栏 `已取消移动，图层位置未改变`，
   撤销计数不变；此时仍按住鼠标继续移动，画面不再跟随，松开也不产生撤销步。
8. 缩放后拖动：`Ctrl+=` 放大到 300% 再拖，鼠标移动 30 屏幕像素约等于 10 文档像素，
   状态栏位移按**文档像素**计数；`Ctrl+0` 适合窗口后再拖，位移仍按文档像素算
   （不因缩放比例改变而翻倍）。
9. 选中**图层组**后拖：组内**所有**成员一起移动，状态栏
   `移动图层组：拖动移动组内 N 个成员（松开算一步撤销）`，`Ctrl+Z` 一步整组复原
   （组自己的 transform 不参与合成，壳搬的是成员；详见 **M30**）。
10. 用 `M` 拉一个选区，选中图层 1 再拖：**只搬选区内的像素**（老行为），
    图层 transform 不变 —— 因此松手后 `Ctrl+Z` 一次也只会退回像素搬移；
    这与第 3 步「整层移动」是两条互斥路径。
11. 把图层全删光（无任何图层）再拖：状态栏 `移动：请先选择一个图层`，
    不产生撤销步、不崩溃。
12. 选中图层 1，**按住 `Alt` 拖动**：按下时状态栏
    `复制并移动图层：拖动即复制一份再移动（松开算一步撤销），当前 (x, y)`；
    拖动中变 `复制并移动图层：(x, y)，位移 (dx, dy)（松开算一步撤销）`。
13. 松开：状态栏 `已复制并移动图层：位移 (dx, dy)（一步撤销）`；
    层面板**多出一层副本**（位于原层之上，名字是 `原名 copy`），原图层**留在原位**没动，
    面板选中项自动跟到副本（接着拖 / 按方向键都是对副本生效）。
14. `Ctrl+Z` 一次：副本**消失且原层仍在原位**（复制与位移在同一个事务里，只有一步）；
    `Ctrl+Y` 恢复副本与新位置。历史面板里这一步的事务名是 `Duplicate & Move Layer`。
15. 按住 `Alt` 在画布上**点一下不拖**就松开：状态栏 `移动：位置未变化`，
    层面板**不新增图层**、撤销计数不变（复制推迟到首次位移，只点不拖不复制）。
16. Move 工具下按**无修饰**方向键（`←` `→` `↑` `↓`）：选中图层按**文档像素** 1 px 微调，
    状态栏 `图层位置：(x, y)（方向键微调）（撤销 N …）`，每按一次撤销计数 +1；
    `Shift+方向` 也是 1 px，`Ctrl+方向` 是 10 px。放大到 300% 再按，位移仍是 1 文档像素。
17. 切到 `B` 再按 `↑/↓`：仍是**切换选中图层**（方向键选层没有被 Move 的微调抢走）；
    选中**组图层**后切回 `V` 按方向键：整个组按 1 px 微调，状态栏
    `图层组：位移 (dx, dy)，N 个成员（方向键微调）`，每按一次算一步撤销（详见 **M30**）。
18. 把图层 1 **整块拖出画布**（向左拖到蓝方块完全看不见）：拖动中状态栏末尾出现
    ` · 已拖出画布`；松开后变成
    `已移动图层：位移 (dx, dy)（一步撤销） · 已拖出画布（图层仍在面板里，可拖回或 Ctrl+Z）`。
    画布上确实一片空白，但层面板里图层还在。
19. 再把它**拖回画布**：提示在进入画布的那一刻消失（每帧重算，不需要手动清），
    松开后文案恢复成只有「位移」。位置提示只在**完全离开**画布后出现。
20. 用方向键把图层**推出画布**（Move 工具下连按 `←`）：状态栏变成
    `图层位置：(x, y)（方向键微调） · 已拖出画布`；按 `Ctrl+Z` 能逐步退回，
    回到画布内后提示消失。注意：提示只看矩形与画布的交集，**部分**露出画布时不提示。

👁 关注：拖动时蓝方块边缘是否**没有半像素抖动**（位移按文档像素取整，
若边缘随鼠标抖半像素说明写的是浮点 transform）；150% DPI 下拖动距离是否与鼠标位移一致；
拖动到画布外再拖回，位置是否仍按原点连续（不应突然跳到鼠标处）；
拖动旋转过的图层时（若手头有带旋转的 `.comp`），旋转角是否保持不变；
Alt+拖动时副本与原层的**堆叠次序**是否稳定（副本在原层之上，不来回跳）；
拖动中**松开 Alt 键**，这一拖是否仍按复制处理（语义在按下时取样一次）。

## M28 Spot Healing（J）（2026-10-21）

> 修补是**一笔一蒙版**：拖过的折线在松手时被光栅化成图层像素空间的 8 位蒙版，
> 交给引擎的 `COMP_TOOL_HEAL` 一次性替换像素。硬度/直径与画笔共用，
> 算法重复按 `J` 切，`Alt+[ / ]` 调不透明度；每一笔（松手）= **恰好一个撤销步**。
> 有选区时蒙版会与选区逐像素相乘（四舍五入），只在选区内落墨。

1. 新建文档（1280×720），用 `U` 在画面左侧画一个红方块、右侧画一个蓝方块（背景层），
   新建图层再用 `B` 画几条黑线（修补会写到当前图层，新建一层更容易看清结果），
   在层面板里选中这条新图层。
2. 按 `J`：工具栏第 11 个按钮（J）高亮；状态栏
   `工具：Spot Healing（J）· Content-Aware｜拖动涂抹要修补的区域，松开应用；再按 J 切算法，[ / ] 调直径、Shift+[ / ] 调硬度、Alt+[ / ] 调不透明度（100%）`。
3. 在画面上按住左键拖一笔：拖动中状态栏
   `修补：拖过要修补的区域，松开应用（Content-Aware · 直径 N px · 不透明度 100%；再按 J 切算法，Alt+[ / ] 调不透明度；有选区时只修补选区内）`；
   拖动中**画面不变**（没有蒙版预览，松手才落墨）。
4. 松开：拖过区域被邻近内容替换（红/蓝方块边缘被抹平或填充），
   状态栏 `修补工具：已应用 N 个折点（Content-Aware · 直径 M px · 不透明度 100%）（撤销 K / 重做 0 · 历史 … KiB）`；
   撤销计数**只加 1**。`Ctrl+Z` 一次整笔回退，`Ctrl+Y` 恢复。
5. 快速横向甩一笔（折点很稀）：整条笔迹**连续被修补**，中间没有圆形断口
   （折线按 1/4 半径步长补点）；若出现一串孤立圆点，说明细分步长太大。
6. 把画笔硬度调到最低（连按 `Shift+[`）：修补边缘**柔和过渡**；调到最高边缘**较硬**；
   把直径调到 20 px 与 200 px 各试一笔：修补覆盖范围随直径变化，
   且**不因画布缩放而变**（`Ctrl+=` 到 300% 后再试，覆盖的文档像素直径不变）。
7. 再按 `J`（当前已是 J）：状态栏 `修补算法：Create Texture（再按 J 切换；Content-Aware / Create Texture / Proximity Match）`；
   再按两次回到 Content-Aware。切到 `B` 再按 `J`：状态栏重新出现工具提示，算法**回到 Content-Aware**
   （不会记住上次会话里的算法）。
8. 默认 100% 时按 `Alt+]`：状态栏仍是 `修补不透明度 100%（…）`（上限 100%，不再上升）；
   `Alt+[` 连按到底：`修补不透明度 10%（…）`，再按不再下降（下限 10%）。
   不透明度 30% 时拖一笔：
   修补结果只是**部分**替换（仍能看到底层纹理），且一次撤销可整笔回退。
9. 放大并平移画布（`Ctrl+=` / 空格拖）后，在某个特征上垂直拖一笔：
   修补区域**正好落在光标下方**，不因缩放/平移整体偏移；再 `Ctrl+0` 回适合窗口重复，
   落点仍一致（若放大后偏一半笔刷，说明折线 → 图层映射漏了缩放）。
10. 选中一个**组图层**后拖：状态栏 `修补：组图层没有像素，无法修补（先选中组里的成员图层）`，
    画面与撤销计数不变。
11. 把图层全部删光（无任何可选图层）后拖：状态栏 `修补：请先选择一个图层`，
    不产生撤销步、不崩溃。
12. 用 `M` 拉一个矩形选区，然后拖一笔**横跨选区边界**（一半在选区内、一半在外）：
    松手后**只有选区内的那半段被修补**，选区外的像素一个没动；
    状态栏末尾多出 `· 按选区裁剪`（`…（Content-Aware · 直径 M px · 不透明度 100%）· 按选区裁剪｜…`）。
    若选区外也被修补了，说明壳侧没叠蒙版（引擎的 heal 路径本来就不看选区）。
13. `Ctrl+D` 取消选区后再拖同一笔：整条笔迹都生效，状态栏**不再**有「按选区裁剪」后缀
    （对照上一步，确认后缀不是恒定的）。再做一次**羽化/半透明边缘**的选区（若当前版本
    不支持羽化，用软边选区近似）横跨边界拖：边界处应是**平滑过渡**而不是一刀切的硬边
    （蒙版逐像素相乘、四舍五入，不应整体变暗或出现亮边）。

👁 关注：修补边缘是否有明显圆形接缝（重叠 stamp 取 `max`，不应出现「越涂越亮」的斑块）；
高硬度 + 小直径时笔迹是否仍是连续胶囊形而不是锯齿点列；
150% DPI 下修补落点与光标是否对齐；`Ctrl+Z` 后画布是否立刻重绘（不应残留半张蒙版）；
在导入的大图上修补（图层像素尺寸大于画布）是否给出明确拒绝文案而不是崩溃；
有选区时修补结果是否**严格被选区框住**（选区外的纹理应当原封不动）。

## M29 面板分界线：拖动调宽 / 双击复位（2026-10-21）

> 图层面板最右 5 px、右侧面板最左 5 px 是分界线（**在面板内侧，不吃画布像素**）。
> 拖动实时生效，画面里的文档保持不动；双击复位到缺省宽度（248 / 330 px），`Esc` 取消。
> 宽度偏好**不进撤销栈**：`Ctrl+Z` 只回滚像素/图层。

1. 打开一个有 3 层以上的文档，窗口拉到 1280×720 或更宽（保证两侧面板都在）。
   指针移到图层面板**最右边缘**（右侧最后 5 px）：光标变成**左右箭头**，该处出现
   一条提亮的竖带与 1 px 亮线；移开 1 px 到画布上：高亮与箭头立刻消失。
2. 按住左键向左慢慢拖：图层面板实时变窄，画布变宽；状态栏
   `图层面板：拖动调宽，双击分界线复位（248 px），Esc 取消` → 拖动中
   `图层面板宽度 N px`。**画面里的图像不回移动**（pan 已补偿画布中心变化）——若图像
   跟着左右平移，说明 pan 补偿漏了。
3. 松手：状态栏 `图层面板宽度：N px（双击分界线复位）`；撤销计数**不变**
   （`Ctrl+Z` 不该把面板宽度退回去，它只回滚像素/图层）。
4. 向右拖到最宽处继续拖：宽度停在 **520 px** 不再增长；此时**立刻反向**往回拖几像素，
   面板应当**马上**开始变窄，没有「先空拖一段才开始动」的死区。
   向左拖到 **168 px** 同理（下限），层名在该宽度下仍能看到前几个字。
5. 双击图层面板分界线：宽度回到 **248 px**，状态栏 `图层面板宽度已复位为 248 px`；
   画布位置同样保持不动。
6. 拖动中途按 `Esc`：宽度**回到按下前的值**（不是停在半路），状态栏不残留拖动文案；
   再按住拖到别处后，用 `Alt+Tab` 切走再切回（捕获被抢）：宽度同样回到按下前的值。
7. 右侧面板重复步 1–5：分界线在右侧面板**最左边缘**（左起 5 px），光标左右箭头，
   向右拖变宽、向左拖变窄，范围 **240–560 px**，双击复位到 **330 px**，状态栏文案
   为 `右侧面板…`。在路径/历史/色彩范围等右侧面板之间切换（`P`/历史按钮等），
   宽度**保持不变**（同一个偏好，不按面板类型分别记）。
8. 把画布拉窄：面板宽度不变，但画布被压缩；再窄到
   `图层面板宽度 + 180 > 窗口宽度` 时，图层面板**整块收起**（不是挤成一条），
   画布占满；此时拖到原分界线位置不应有任何反应（命中带已随面板消失）。
   若为了拖宽而让面板在窄窗口里被收起，状态栏会追加
   `（当前窗口放不下，已收起；放宽窗口后生效）`——把窗口拉宽后面板按新宽度出现。
9. 用画笔在画布**最左一列像素**上落笔（放大到 400% 更好看清）：正常落色，
   不会把图层面板拉宽；同理在画布**最右一列**落笔不会触发右侧面板缩放。

👁 关注：高亮度竖带是否只在悬停/拖动时出现（常态应只有 1 px 暗线，别把 5 px 全点亮，
面板内容会显得被切了一刀）；150% DPI 下分界线宽度与箭头位置是否仍对得上；
拖动过程中画布重绘是否跟手（不应每帧整窗闪烁）；把窗口拉得很宽（1920+）时
把两侧都拉到最大，画布仍应保留 ≥180 px 且不出现负宽度。

## M30 整组移动：拖动 / 方向键搬整个组（2026-10-21）

> 组自己的 transform 不参与合成（`filter_graph` 只烘焙成员），所以移动组 = 平移组内
> **每个成员**。判定沿 `parent` 链走，嵌套组一并移动；一次拖动（或一次按键）= 一步撤销。
> 空组不写文档，只提示「组内没有成员，无位移」。

1. 打开一个有 3 层以上的文档，在图层面板里 `Ctrl+点击` 选中其中两层，按 `Ctrl+G`：
   新建的组出现在面板顶部并自动选中（状态栏 `已新建组 #…（收入 2 个图层）`）。
2. 切到 Move 工具（`V`），确认**没有选区**（`Ctrl+D`）。在画布上按住左键拖动：
   组里的**所有**成员一起跟手移动，不在组里的图层不动；状态栏
   `移动图层组：拖动移动组内 2 个成员（松开算一步撤销）` → 拖动中
   `移动图层组：位移 (dx, dy)，2 个成员（松开算一步撤销）`。
3. 松手：状态栏 `已移动图层组：位移 (dx, dy)，2 个成员（一步撤销）`；
   按一次 `Ctrl+Z`：整组**一步**回到拖动前的位置（不是一层一层退）。
4. 无选区时按方向键（Move 工具）：整个组按 1 px 移动；`Shift+方向` 仍是 1 px、
   `Ctrl+方向` 仍是 10 px。状态栏
   `图层组：位移 (dx, dy)，2 个成员（方向键微调）`，每按一次是一步撤销。
5. 在图层面板里把组展开（点组行左侧三角），确认组内成员的 `x/y` 都变了相同的量，
   而**组行自己**的位置数值没有变化（组不写自己的 transform）。
6. 嵌套：把已有的一组再 `Ctrl+G` 收进新组（或直接把组拖进另一个组），选中**外层组**
   拖动：外层与内层成员**全部**一起移动，不出现「外层动了、内层留在原地」。
7. 整组拖出画布：所有成员都离开画布后才追加 ` · 已拖出画布`；只要还有一个成员可见，
   提示就不出现（保守口径，避免误报「图层丢了」）。拖回画布提示消失，无需撤销。
8. Alt 拖动组（按住 `Alt` 再拖）：原组**留在原地**，画布上出现一份深拷贝跟着指针走；
   状态栏 `复制并移动图层组：…`。松手后 `Ctrl+Z` 一步同时撤掉副本与位移。
   继续拖动副本时动的是**副本**，原组不动。
9. 只点不拖（按下立即松开）：状态栏 `移动图层组：位置未变化`，撤销计数不变；
   拖动中途按 `Esc`：整组回到按下前位置，撤销计数同样不变。
10. 若文档里有**空组**（组内成员已删除或移出）：选中它拖动 / 按方向键，状态栏
    `移动图层组：组内没有成员，无位移` / `图层位置：组内没有成员，无位移`，
    画面不应有任何变化（也不产生撤销步）。

👁 关注：拖动整组时是否**所有**成员同步移动（有一个成员掉队 = 子树判定漏了某级父链）；
有无抖动或逐帧取整漂移（来回拖回原点应精确复原）；Alt 复制后是否动的是副本
（原组跟着动就是成员快照没按副本重建）；大组（20+ 成员）拖动是否仍跟手。

## M31 滤镜实时预览：调参即出帧，文档不动（2026-10-21）

> 预览帧**只活在 framebuffer 里**：每次改参数走一遍
> `comp_txn_begin` → 应用一次 → 取帧 → `comp_txn_abort`，事务回滚把像素还回去，画面留在这帧。
> 所以文档、撤销栈、图层修订号始终停在「改参数之前」——关面板 / 换面板 / 换文档 / 切工具
> 都不需要收拾半开事务。回车才是真应用；任何重画（`needs_render`）都会顶掉预览帧。

1. 打开文档，选中一个**像素图层**，菜单「滤镜（Filter）」里挑一个滤镜（例如 Gaussian Blur）。
   面板标题 `滤镜（Filter）`，状态栏
   `滤镜：<滤镜名>（Tab 选参数 · -/= 调值即预览 · 数字键入 · 回车应用 · Esc 关闭）`。
2. 按 `Tab` / `Shift+Tab` 选参数行，用 `-` / `=` 调值：**每按一次画面立刻变**，
   状态栏 `<参数> = <值>（步长 <step>） · 预览中（回车应用 · Esc 取消）`。
   反复加减几次，确认画面**跟着当前值走**，不是叠加（叠了就是把预览当真写进文档了）。
3. 预览期间按 `Ctrl+Z` 之外的方式观察撤销栈（或看状态栏的撤回计数）：
   **不增长**——预览不是一步撤销。再按 `Backspace` 复位参数：状态栏
   `滤镜参数已重置为默认值 · 预览中（回车应用 · Esc 取消）`（默认值若正好恒等则后缀变
   ` · 参数为恒等，无预览`，画面回到原样）。
4. 直接按 `Esc` 关闭面板：画面**逐字节**回到预览前的样子，状态栏
   `已关闭滤镜面板（预览已丢弃，图层未改动）`；没预览过则是 `已关闭滤镜面板`。
   此时 `Ctrl+Z` 应撤掉的是**预览之前**的那一步（预览没占撤销位）。
5. 重新开面板、调好值，按**回车**：状态栏 `<滤镜名>：已应用`（引擎有 note 时追加 `｜…`），
   随后一行是历史/撤回计数——**恰好 +1 步**。画面应与刚才的预览帧**完全一致**
   （不一致说明预览与真应用走了不同参数，属缺陷）。
6. 恒等参数（例如 Amount 仍为 0）下按 `-`/`=`/`Backspace`：状态栏 `… · 参数为恒等，无预览`，
   画面不动；此时回车得到 `<滤镜名>：参数为恒等，未改动`，撤销计数不变。
7. 没有选中图层（或用 `↑↓` 把选择移空）时调参：状态栏
   `滤镜预览：请先用 ↑↓ 选择一个图层`，像素不动；回车仍会提示 `请先用 ↑↓ 选择一个图层`。
8. 数字键键入参数：输入串显示在面板底部 `输入中：…`，**只改文本不出预览**；
   回车 = 落值并直接应用（`<滤镜名>：已应用`），不会先闪一帧预览。
   `Esc`（输入态）只取消这次键入（`已取消输入`），面板与画面都不变。
9. Progressive Blur：在画布上按住左键拖一条轴，松手即按这条轴出预览，状态栏
   `Progressive Blur 渐变轴：(x1, y1) → (x2, y2) · 预览中（回车应用 · Esc 取消）`；
   拖得太短（起终点几乎重合）则 `Progressive Blur：轴太短，已放弃（需要一条可定义的方向）`，
   画面不动。轴端点是文档坐标：换文档后自动作废（不会拿旧文档的轴去预览新文档）。
10. 面板打开时点画布（非 Progressive 轴拖拽）：状态栏
    `滤镜面板打开中：画布点击不作用于工具（Esc 关闭面板）`，**不画图、不建选区**；
    滚轮 / `Ctrl+滚轮` 缩放仍可用，缩放**不会**把预览顶掉（只改视图，不重画文档）。
11. 预览中切换工具、打开别的面板、新建/打开文档：预览一律丢弃，画面回到文档真状态，
    不会带着一帧假像素进新上下文。

👁 关注：连按 `-`/`=` 时画面是否**每次都是当前值的完整应用**（叠加/残影 = 事务没回滚）；
预览期间撤销栈是否**一动不动**（长了 = 预览落了文档）；`Esc` 后与原图逐字节一致
（把 B 通道也看一眼，别只看红绿）；回车结果与预览帧是否一致（同一组参数两遍算出不同像素
= `build_filter_desc` 两次取到的值不同）；面板开着时在画布上乱点是否**改坏像素**；
Progressive 轴预览与回车后结果是否同一条轴。

## M32 Move：有选区时按落点分流（2026-10-21）

> 有选区时上游 V 看**落点**：点在选区内 = 搬选区像素（蚂蚁线跟着走）；点在**画布内、
> 选区轮廓外** = 搬整层（只改 transform，像素不动，选区原地不动）。判定阈值 128，
> 与蚂蚁线同一口径；蒙版读不到时退回搬像素的旧行为，不猜。

1. 打开文档，选中一个像素图层，用选框工具拉一块**没有盖满图层**的选区（例如图层 200×200、
   选区 60×60 在中间）。切到 Move 工具（`V`）：工具栏提示里应写着
   「有选区 = 选区内搬像素（Alt = 复制）、选区外拖整层」。
2. 在**选区内**按住拖动：状态栏 `移动选区像素：松开提交（按住 Alt = 复制）`，
   蚂蚁线跟着指针走；松手 `已移动选区像素：位移 (dx, dy) px，N 个像素`。
   `Ctrl+Z` 一步复原（像素与蚂蚁线一起回来）。
3. 在**选区外、画布内**按住拖动：状态栏
   `移动图层：拖动改变位置（松开算一步撤销），当前 (x, y) · 落点在选区外：移动整层，选区不动`。
   拖动时整层跟手平移，**蚂蚁线留在原地**；松手 `已移动图层：位移 (dx, dy)（一步撤销）`，
   `Ctrl+Z` 一步回到原位（选区始终没变）。
4. 选区外按住 `Alt` 再拖：状态栏 `复制并移动图层：拖动即复制一份再移动（松开算一步撤销），
   当前 (x, y) · 落点在选区外：移动整层，选区不动`；松手
   `已复制并移动图层：位移 (dx, dy)（一步撤销）`。原层留在原地、副层跟着走，
   一步撤销同时撤掉副本与位移。
5. 羽化边界：把选区羽化到 30 左右，点**半透明边缘**（coverage < 128）拖动 → 走整层；
   点**不透明核心**（coverage 255）拖动 → 搬像素。边界值 128 本身算「里面」。
6. 画布**外的空白处**（窗口背景、面板上）按下：本来就不是拖动起点，画面与状态栏都不该变；
   本项只改画布内的分流。
7. 无选区时（`Ctrl+D`）行为一字未变：拖动仍是整层、`Alt` 仍是复制整层。
8. 选中**组图层**且有选区、落点在选区外拖动：整组一起平移（§5.34），状态栏
   `移动图层组：拖动移动组内 N 个成员（松开算一步撤销） · 落点在选区外：移动整层，选区不动`；
   组自己的 transform 仍不被写。
9. 选区外拖动中途按 `Esc`：图层回到按下前位置（`已取消移动，图层位置未改变`），
   撤销计数不变。

👁 关注：选区外拖动时**像素是否一个都没被搬**（画面里选区外的内容形状不变，只是整体位移）；
蚂蚁线是否**原地不动**（跟着走 = 又走了搬像素那条路）；状态栏后缀是否真的出现
（没有后缀时用户不知道自己在动整层）；羽化边上 127/128 的分界是否与蚂蚁线一致；
`Alt` 在选区外拖是否复制的是整层（原层不动）；反复在选区边界内外按下，分流是否稳定。

## M33 多选批量移动：拖动 / 方向键搬整批（2026-10-21）

> 面板里 Ctrl 点选多个图层后，拖动与方向键都作用**整个选中集合**（整批一个事务 = 一步撤销）。
> 选中项是组时按子树成员展开；被选中的祖先组已覆盖的子层不会重复写。

1. 打开文档，建 3 个错开的像素图层。在图层面板点第一行，`Ctrl+`点另外两行（三行都高亮），
   切到 Move（`V`）：工具栏提示里应写着「面板多选 = 整批移动（Alt = 整批复制）」。
2. 在画布上按住拖动：状态栏 `移动多个图层：拖动移动 N 个成员（松开算一步撤销）`；
   拖动中出现位移提示 `移动多个图层：位移 (dx, dy)，N 个成员（松开算一步撤销）`。
   **三个图层同时跟手**，两两之间的相对位置不变（不是只有一个在动）。
3. 松手：`已移动多个图层：位移 (dx, dy)，N 个成员（一步撤销）`。`Ctrl+Z` **一步**让三层
   全部回到原位（撤销栈里只有一条，不是一个图层一条）。
4. 保持三行选中，按方向键：`图层：位移 (1, 0)，N 个成员（方向键微调）`，同样三层一起动；
   `Ctrl+方向键` 一次 10 px（方向键本身 1 px），口径不变；`Ctrl+Z` 一次撤回整批。
5. 选中一个**组**加一个普通层再拖动：组的成员数 + 普通层 1 个一起搬；状态栏是
   `移动多个图层：…`（不是 `移动图层组：…`），且组自身 transform 仍不被写。
6. 选中**祖先组**和它的**子层**再拖动：子层只被搬一次（`N 个成员` 不含重复项），
   画面上不会出现「位移了两倍」。
7. 按住 `Alt` 拖动：开始是 `复制并移动多个图层：拖动即复制整批再移动（N 个成员，松开算一步撤销）`，
   拖动中 `复制并移动多个图层：位移 (dx, dy)，N 个成员（松开算一步撤销）`，松手
   `已复制并移动多个图层：位移 (dx, dy)，N 个成员（一步撤销）`。**每一层都多出一个副本**
   （组是整棵子树的深拷贝），原层原地不动，一步撤销同时撤掉所有副本与位移。
8. 只点不拖（按下不移动就松开）或多选全是空组时按拖动：前者 `移动多个图层：位置未变化`，
   后者 `移动多个图层：选中的图层没有可移动的成员，无位移`；两种都不该在撤销栈里多一步。
9. 多选拖动到整批离开画布：拖动中补 ` · 已拖出画布`，松手
   ` · 已拖出画布（图层仍在面板里，可拖回或 Ctrl+Z）`。拖动中途按 `Esc`：
   `已取消移动，图层位置未改变`，所有选中项都回到按下前位置。

👁 关注：拖动时**几个图层是不是同步位移**（只动一个是旧行为）；松手后撤销是否只占**一步**；
被祖先组覆盖的子层是否被**重复搬**（看起来位移翻倍）；Alt 拖动后副本层数是否等于选中项数乘以
各自成员数；组多选时组自身 transform 是否仍未被写（撤销后组属性不变）；`Esc` 后是否有图层
停在半路。

## M34 多选批量开关图层效果（2026-10-21）

> 面板里 Ctrl 点选多个**普通**图层后，效果菜单（描边/投影/颜色叠加/内阴影/外发光/内发光）
> 一次作用于整批：主选中层决定「加还是减」，整批一个事务 = 一步撤销。组图层会被跳过并说明。

1. 打开文档，建 3 个错开的**普通像素图层**，在图层面板 Ctrl 点选三行。
2. 主选中层当前没有投影时，点效果菜单的「投影」：状态栏
   `已为 3 个图层添加效果：投影`；三行都应出现 fx 标记，画面上三层都有投影。
3. `Ctrl+Z` **一步**让三层投影同时消失（撤销栈只有一条 `Add Effect To Layers`）。
4. 重做（`Ctrl+Y`）后，保持三行选中再点一次「投影」：状态栏
   `已为 3 个图层移除效果：投影`，三层同时恢复；再 `Ctrl+Z` 一步全回来。
5. 选中集合里有一层**本来就有**该效果、其余没有：添加时那层被算作
   「已在目标状态」，状态栏追加 `（K 个已在目标状态）`，且它自己的参数**没有被重置**
   （效果是 `{}` 默认参数时看不出区别，可先手动改过它的距离/角度再验）。
6. 选中集合里包含**组图层**并加效果：组被跳过，状态栏追加
   ` · 跳过 N 个组图层（引擎不按组求值效果）`；组内的普通成员该不该动？——不会动，

7. **单选**组图层时点效果菜单：状态栏

8. 多选后按 `Ctrl+Shift+E` 打开参数面板：面板显示的是**主选中层**的效果参数；
   改值只写主选中层（批量改参数未做），关掉面板后其余层的参数应保持原样。

👁 关注：三步效果是否**同时出现/同时消失**（只动一行是旧行为）；撤销是否只占**一步**；
组图层有没有被写上「看不见的效果」（fx 标记出现但画面不变 = 静默无操作）；
「已在目标状态」的层参数是否被静默重置；单选组时菜单是否还假装勾上了。

## M35 变换手柄：拖动缩放 / 旋转（2026-10-21）

> Move 工具下选中**一个有显式变换的普通图层**，画布上出现蓝色框 + 8 个白底方块 +
> 上方旋钮（带引线）。拖方块改尺寸（对角锚点不动），拖旋钮改角度，Shift 吸附 15°，
> 一次拖动只占一步撤销。

**准备**：建一个普通图层，先让它有显式变换——选中图层后按 `Alt+[` 或 `Alt+]`
（状态栏出现 `图层尺寸：W×H（Alt+[ ]，中心锚定）`），或者拖动它一次。若图层
从未有过显式变换（`w/h <= 0`，按像素尺寸），不要用这些图层验证，见第 7 条。

1. 选中该图层、切到 Move（`V`）：画布上应看到 1 px 蓝色矩形框贴着图层边缘，
   四角与四边中点各一个白底方块，上边中点正上方 24 px 处一个圆点，两者之间有引线。
2. 拖**右边中点**方块向右：框与图层一起变宽，**左边**固定不动，状态栏实时显示
   `缩放图层：W×H（位置 (x, y)）`；松手后变成
   `已缩放图层：W×H，位置 (x, y)（一步撤销）`，`Ctrl+Z` 一步回到原来的尺寸。
3. 拖**左上角**方块向左上：右下角固定不动（对角锚点），框跟着手指走。
4. 把指针拖过对边（拖右边中点一路拖到左边以左）：宽被压到下限（1 px）而不是变成
   0 或负数；继续往左拖也不会翻转。
5. 拖**旋钮**绕图层中心转：状态栏实时显示 `旋转图层：N°`，松手
   `已旋转图层：N°（一步撤销）`；按住 `Shift` 时角度只落在 15° 的整数倍上。
   转到 90° 后，方块应跟着框一起转（仍然贴在旋转后的角上），而不是留在原位。
6. **旋转后再缩放**：在 90° 状态下拖右边中点，被拖的那条边的**对边中点**应保持
   在屏幕上不动（图层不会被顺带推走）。
7. 切换到**组图层**、或**多选**两行、或图层从没有过显式变换（`w/h <= 0`）：
   都不画变换框，拖动画布仍是「搬整层」。有像素选区（蚂蚁线在）时同理不画框，
   拖动按 M32 的落点分流走。
8. 拖着手柄时按 `Esc`、或把窗口切走（失焦）：拖动被取消，图层回到按下前的
   尺寸/角度，状态栏不留「进行中」字样；只点一下手柄不拖，松手应提示
   `缩放：尺寸未变化` / `旋转：角度未变化`，且**不产生**撤销步。

👁 关注：框和手柄是否**贴在图层边缘**（尤其旋转 90°/45° 之后——错开说明绕错了
中心）；缩放时对角的锚点是否**纹丝不动**（图层被顺带平移是常见错法）；一次拖动
是否只占**一步**撤销；无变换/组/多选/有选区时是否**老老实实不画框**（画了但又
缩不动，比不画更糟）；光标在画布上**不会**因为悬停手柄而变形（已知边界，不算失败）。

## M36 工具图标：20 个按钮的形状（2026-10-21）

## M38 连续方向键微调合并为一步撤销（2026-10-21）

> 按住方向键挪图层几秒，历史里只应多出**一步**；松手后一次 `Ctrl+Z` 回到按住之前。
> 点按（按下即松）仍是一下一步。

**准备**：启动壳，加一层（`Ctrl+Shift+N`），切 Move 工具（`V`），在面板里选中这层。
状态栏的历史计数（`撤销 N / 重做 M`）是本项的尺子。

1. 点一下 `→`：图层右移 1 px，松手后状态栏回到历史计数样式，记下「撤销 N」。
2. 按住 `→` 约 1–2 秒再松手：位置连续右移十几像素（自动重复），松手后「撤销」只比
   第 1 步多 **1**。
3. 按一次 `Ctrl+Z`：图层**一次退回**按住之前的 x，不是退一格；「重做」加 1。
4. 再连点 5 下 `→`（每下都松键）：应占 **5** 步，连按 5 次 `Ctrl+Z` 逐格退回。
5. 混序列：按住 `→` 一段 → 松手 → 点菜单 `图层 → 平移右`：应是两步，
   第一次 `Ctrl+Z` 退菜单那一步（只回 1 px），第二次退整段按键。
6. 按住 `→` 不放，中途按 `Ctrl+Z`：不崩溃、不报「无法撤销」；已产生的位移作为一步被撤销，
   仍按着键继续移动只是另一段（松手后又是一步）。
7. 按住 `→` 不放，中途点另一图层行（鼠标按下即触发收口）：状态栏不应出现事务相关的报错，
   后续 `Ctrl+Z` 顺序正常。

👁 关注：一次按住只吃一步（第 2–3 步）；点按仍是一下一步（第 4 步）；
不同来源（按键段 / 菜单项）**不并进同一步**（第 5 步）；中途被别的操作打断时
历史里不出现「空步」（撤销了一次但画面没变）。

## M39 Shift 拖角 = 等比缩放（2026-10-21）

> Move 工具下拖角手柄改变尺寸时，按住 `Shift` 应保持图层原有的宽高比；
> 松开 `Shift` 立刻回到自由缩放。整段拖动仍是一步撤销。

**准备**：加一层图元（例如 `Ctrl+Shift+N` 后画一笔，或打开带变换的文档），
切 Move 工具（`V`），面板里单选该层，让它出现变换手柄（需要该层有显式宽高）。

1. 拖**右下角**手柄向右下：宽高各自跟随指针（形状会被拉扁）。
2. 回到原位，同样拖右下角但**按住 `Shift`**：形状保持原比例变大，左上角不动；
   状态栏末尾出现「等比」。
3. 拖动途中按下 / 松开 `Shift`：尺寸立即在「自由」与「等比」之间切换，不跳位置。
4. 拖**右边中点**手柄（边手柄）时按住 `Shift`：应与不按完全一样（边手柄不做等比）。
5. 把角手柄拖到与对角重合再往外一点：两边都不会变成 0，比例仍成立。
6. 旋转一个角度（拖旋钮）后再 `Shift` 拖角：对角（旋转后的那个角）在画面上不动，
   形状仍不歪。
7. 整段 `Shift` 拖动后按一次 `Ctrl+Z`：一次回到拖动之前（不是逐帧回退）。

👁 关注：等比时比例是否**一直是按下那一刻的比例**（来回拖不漂）；
对角是否真的钉住（旋转过的层也要看）；边手柄是否**没有**被 `Shift` 影响。

## M40 树形图层面板：组在上、缩进、可折叠（2026-10-21）

> 有组的文档里，面板应像 PS 一样是**树**：组行在上、子层缩进列在下方；组行首的三角
> 可以折叠整棵子树。上移/下移/拖拽只在**同级**里换位。

**准备**：新建文档，`Ctrl+Shift+N` 加出 3 个图元层（每层画一笔以便区分）。多选其中两层
（点第一行，再 `Ctrl+点` 第二行），`Ctrl+G` 建组。

1. 看面板：组行在**最上面**，被收进组的两层缩进一格列在组行**下方**，第三层不缩进，
   仍在组下方。旧版这里是子层压在组行上面。
2. 组行行首有 ▾ 三角；子层行首留同样宽的空槽（名字与同层级对齐）。
3. 点组行的 ▾：子树整段收起，只剩组行，三角变 ▸，状态栏提示「已折叠组 #…」
   （行数变小）。再点 ▸ 恢复，顺序不变。
4. 折叠状态下点组行再 `Ctrl+Z`：**不应**有任何撤销步——折叠是视图态，不写文档。
5. 折叠着编辑：把主选中层换成组里某层（展开后选中），再折叠，选中自动落到组行上，
   不会「看不见却还选中」。
6. 选中组里**唯一**的子层按 `Ctrl+Shift+↑`（上移）：应提示「已经是顶层」而不是真的挪出去；
   组里两个子层时，下层上移/上层下移应与下方另一子层交换，跨出组则不做。
7. 选中组行本身按 `Ctrl+Shift+↑`：只在根层之间换位，组连同子树整体移动。
8. 把根层行拖到组行的**中间带**：整层移入组末尾，缩进立即生效（一条撤销步）；
   把组内子层拖到根层行：移出到根级（一条撤销步）；拖到别的组里、或把组拖进自己
   的子树：状态栏明确拒绝，数据不变。
9. 组内拖拽时的蓝色落点线落在**可见行**的位置上；折叠掉的子层不占行，也不会成为落点。
10. 双击组行的三角槽位：只折叠/展开，**不**弹出改名框；双击组名本身仍进改名。
11. 深层嵌套（三层以上组）：缩进最多到第 6 级就不再右推，名字不会被挤出面板栏宽。
12. 结构变化（移入/移出/重排/撤销）后选中态跟着**那一层**走，而不是跟着行号走。

👁 关注：组行是否稳定在上面（不是子层在上）；折叠后行数、选中行、批量命令的计数是否
一致；拖到组内/根级的落点提示是否与最终结果相符；每一步撤销是否只回退一步。

## M42 选区扩缩手柄：拖四个角与四条边（2026-10-22）

> 画好一个选区后，四条边和四个角上应出现 8 个小方块把手。拖把手 = 把选区
> 缩放到你拖到的矩形：内容（含抗锯齿边）跟着重采样，**羽化值不变**，
> 松手一次只算**一步撤销**；没拖动就松手不该产生撤销步。

**准备**：新建 800×600 文档，选「选框」工具（`M`），拉一个约 300×200 的矩形选区，
再把羽化设成 6 px（面板或菜单）。当前工具保持为**选框 / 套索 / 魔棒 / 移动**之一。

1. 选区出现后，看四条边中点与四个角：各有 1 个 7×7 的白底黑框小方块，共 8 个。
   方块**贴在选区边框上**，不是贴在羽化外扩的那圈虚影上。
2. 把鼠标依次移到四个角上：光标应变成**斜双箭头**（左上/右下为 ↖↘ 方向，
   右上/左下为 ↗↙ 方向）；移到四条边中点上，光标变成**单轴双箭头**
   （上下边为 ↕，左右边为 ↔）。移开把手恢复当前工具的光标。
3. 拖右边中点向右 100 px：**只有右边界**移动，左/上/下边不动；拖动过程中
   有一个白+黑虚线的预览矩形跟着走，松手后选区变成新矩形，蚂蚁线立刻更新。
4. 拖左上角到 (x-80, y-60)：左、上边界同时移动，右下角不动；四个角都试一遍，
   行为应一致（每个角拖自己那两条边）。
5. 按住 `Shift` 再拖**角**：宽高比锁定为拖动前的比例，缩放锚点是对角线另一端；
   往右拖得多还是往下拖得多都不该把比例带歪（内部按主导轴取宽）。
   按住 `Shift` 拖**边**：与不按一样（边手柄不做等比）。
6. 拖动中按 `Esc`：预览框消失，选区**原样恢复**（松手也不生效）；
   此时按 `Ctrl+Z` **不应**出现「缩放选区」这一步。
7. 拖动中把窗口切到别的程序（Alt+Tab）再切回来：预览取消，选区不变，
   不应留下「按着不放」的卡死状态。
8. 一次有效拖动后按 `Ctrl+Z`：选区整体回到拖动前的矩形（形状与位置都对），
   **一步**就回到位；再按 `Ctrl+Shift+Z` 恢复缩放后的矩形。
9. 点住把手（1~2 px 内不动）再松手：状态栏提示「选区未变化」，
   `Ctrl+Z` **不应**多出一步。
10. 缩放前后看羽化：数值仍是 6 px（面板读数不变），但边缘渐变的**宽度跟着缩放**
    （放大后渐变更宽、缩小后更窄）——羽化是参数，几何变了它就跟着变。
11. 把某个角拖过对边（例如拖左边一直拖到右边之外）：选区夹到 1 px 宽并停住，
    **不会镜像翻转**；继续拖回来能正常恢复。
12. 把选区拖到画布外（左边拖到负坐标）：画布外部分自然丢弃，
    可见部分仍正确，不崩、不出现越界绘制的把手。
13. 把手大小：用缩放工具放大到 400% 再缩到 25%，把手**仍是 7×7 屏幕像素**，
    不随画布缩放变大变小；命中范围与画上去的方块一致（点方块边缘仍能抓住）。
14. 切到「画笔」工具（`B`）：8 个把手**都不应**出现，画笔落点不会被把手抢走；
    切回选框/套索/魔棒/移动，把手重新出现。
15. 选中多个图层或调了不透明度后再拖把手：只影响选区几何，图层内容与参数不变。

👁 关注：把手是否**贴在**选区真实边界（而非羽化外扩圈）上；拖动是否「只有被拖的边动」；
松手前后选区内容是否连贯（没有整体跳位）；`Shift` 比例锁与 `Esc` 取消是否稳定；
撤销粒度是否「一次拖动一步」；放大画布后把手是否仍然好点。

4. 回车提交：画布上应出现**真实汉字**（笔画可辨、抗锯齿），不是 `.notdef` 方框、
   不是空白；字体大小 48 px 时字高约 48 px（比旧点阵明显细腻）。
5. 退格：再打「你好」，按一次 `Backspace` 应删掉**整个**「好」字（不是半个字节、
   不会让后面的字变乱码），再按一次删掉「你」。
6. 撤销：`Ctrl+Z` 一步应整段消失、像素逐字节回到落笔前（不是只删一半）；
   `Ctrl+Shift+Z` 一步回来。
7. 多行：`Shift+Enter` 换行后再打一行，两行行距应等于「字号 × 行距%」
   （48 px × 125% = 60 px），面板行距值改了预览框与落笔结果**同时**变。
8. 缺字：打一个字体子集里没有的符号（emoji 是现成的例子）——该字位置应
   **留空但占位**（后面的字不被挤到前面），状态栏/note 应如实报「without a glyph」
   个数，不画 `.notdef` 方框。
9. 字距/字号切换量纲：字体轨道下把字号从 48 改到 24，字应变**小一半**
   （em 高），不是「格子高」；切回点阵后同样数字变大（格高）。
10. 与旧轨道共存：切回 `5×7 点阵`，打 `ABC` 提交——应是熟悉的 5×7 点阵字形，
    与 P5-2 之前逐字节一致；两段文字在同层共存、互不影响。
11. 取消：键入态按 `Esc` 只丢预览，`Ctrl+Z` **不应**多出一步。
12. 快捷键不误触：键入态按 `[` 应改字号而**不应**同时打出一个 `[`；
    按 `B` 应打出字母 `b` 而不是切到画笔。

👁 关注：中文是否**真的**画出来（不是方框/空白）；输入法上屏是否重复；退格是否
按整字删；`font_size` 在两条轨道上的含义是否与状态栏写的一致；预览框的 `≈` 尺寸
与落笔结果是否大致相符（估计值允许 ±5%）；候选窗位置是否挡住插入点。

## M44 文档级对话框：新建 / 图像大小 / 画布大小 / 历史容量（2026-10-22）

> 四个面板都画在**右栏**（调整面板的位置），键盘归面板：Tab 切行、数字键直接输入、
> 回车应用、Esc 撤草稿再关面板；Ctrl 组合键仍可用。`Ctrl+N` 仍是**立即新建**
> （不弹面板），带参数的入口是 `Ctrl+Alt+N`。

**准备**：启动后先 `Ctrl+N` 得到一个 1280×720 透明文档。

1. `Ctrl+Alt+N`：右栏出现「新建文档」面板，四行（宽 / 高 / 分辨率 / 背景），
   首行高亮。按 `6 4 0`、`Tab`、`4 8 0`、回车：画布换成 640×480（状态栏与
   「适合窗口」后的画布形状一致），面板关闭。
2. 再开一次 `Ctrl+Alt+N`：宽高应**记得上次的 640/480**（不是回到 1280×720）。
   在背景行按空格循环 白 → 透明 → 前景色；选「白色」后回车：新画布应为白底，
   且标题栏出现 ` *`（有内容未保存）。
3. `Ctrl+Alt+I`（图像大小）：默认「约束比例 = 开」。先把宽改成 320（回车前
   高度应自动变 240），Esc 取消后画布不变；再开一次，`Tab Tab` 到约束比例按
   **空格**关掉，回宽度行设 320、`Tab` 设 120、回车：画布变 320×120（比例 8:3）。
   面板副标题应如实写「整篇重采样；选区会被丢弃」。
4. `Ctrl+Alt+C`（画布大小）：宽度设 520、锚点保持居中、回车：画布变 520×120，
   **原有内容水平居中**（左右各扩 100 px）。如果文档里有组，展开/折叠都试一次：
   组内子层必须跟着一起移，不能只有根层动。
5. `Ctrl+Alt+H`（历史记录容量）：两行显示「0 = 引擎默认」；改成 50 步回车后，
   连续做 60 次操作：状态栏的历史读数后应出现「，已截断」（说明第 10 步已被丢弃），
   且撤销到能到的最早状态时程序不崩、画布内容自洽。
6. `文件 > 另存为…`（`Ctrl+Alt+S`）存成任意 `.comp`；再改一笔后按 `Ctrl+S`：
   **不应**再弹保存框（直接写回原路径），标题栏 ` *` 消失。

**不该发生**：对话框开着时按 `B`/`V` 等字母键**不应**切工具；按空格**不应**变成
临时抓手（空格应翻当前行的开关/背景/锚点）；Esc 一次只撤输入草稿、再按一次才关面板。

## M45 Camera Raw 滤镜入口（2026-10-22）

> `滤镜 > Camera Raw 滤镜…`（`Ctrl+Alt+R`）复用文档对话框的右栏面板与键盘模型：
> Tab 切 12 行、负值用 `-` 开头、回车应用、Esc 取消。写的是**选中图层整层**
> （不做选区蒙版），一步撤销。12 行 = 曝光（0.01 EV 整数单位）、色温、色调、
> 对比、高光、阴影、白色、黑色、清晰度、鲜艳度、饱和度、去雾。

**准备**：新建文档，用形状工具画一个 `#808080` 的灰块（或打开一张照片），
保持该图层选中。

1. `Ctrl+Alt+R`：右栏出现面板，标题「Camera Raw 滤镜」，第一行是高亮的
   「曝光 (0.01 EV)」。
2. 键入 `100`、回车：灰块明显变亮（+1.00 EV）；状态栏给出已应用提示，
   标题栏出现 ` *`。
3. `Ctrl+Z`：灰块回到原亮度（**一步**撤销，不是两步）。
4. 再开面板，键入 `-100`、回车：灰块变暗（-1.00 EV）。负号必须能起输入，
   而不是被当成「步进 -1」。
5. 不选任何图层（或选中组图层）时按 `Ctrl+Alt+R`：面板**不打开**，状态栏
   说明原因；组图层由引擎拒绝（`COMP_ERR_STATE`），面板留在原地、参数不丢。
6. 全部行保持 0 直接回车：面板不关闭，状态栏提示「设置等于默认值，像素未
   改动（未产生撤销步）」——恒等设置不写像素、不记历史。
7. 删掉/改名 `resources/camera_raw_tables.bin` 再启动：程序照常启动，打开面板
   时状态栏如实说「色彩表未加载」，不崩。

**不该发生**：应用失败时面板**不应**关闭（参数要留着）；不应影响未选中的
图层；不应产生两个撤销步。

## M46 剪贴板：拷贝 / 剪切 / 粘贴 / 贴入选区 / 清除（2026-10-22）

> `编辑` 菜单：拷贝 `Ctrl+C`、合并拷贝 `Ctrl+Shift+C`、剪切 `Ctrl+X`、粘贴 `Ctrl+V`、
> 贴入选区 `Ctrl+Alt+V`、清除 `Backspace`。本程序内往返走自定义剪贴板格式，
> 8 位图层逐字节相等（含 alpha）；跨应用走 `CF_DIBV5`（32 位、直通 alpha）。
> 粘贴是**新图层 + 一步撤销**；`Del` 仍是删图层，`Ctrl+Shift+V` 仍是切图层可见性。

**准备**：`Ctrl+N` 新建文档，用形状工具画一块满幅或大半幅的橙色矩形。

1. 不建选区直接 `Ctrl+C`，再 `Backspace`：画布清空（黑/透明）；`Ctrl+V`：橙色
   按原位置回来，图层面板多出一层「粘贴的图层」。`Ctrl+Z`：新层消失（**一步**）。
2. 拉一个矩形选区盖住左半，`Ctrl+Alt+V`：橙色只出现在选区里，选区外仍是空；
   `Ctrl+Z` 一步回到粘贴前。
3. `Ctrl+D` 取消选区，再 `Ctrl+Z` 撤销掉清除，然后 `Ctrl+X`：画布清空，
   再 `Ctrl+V`：内容与剪切前一致（剪贴板先写成功才清像素）。
4. 打开记事本/画图，`Ctrl+V`：应能粘出一张位图，颜色与画布一致（跨应用路径）；
   反过来从画图复制一块贴回来，应落在 (0,0)，成为新图层。
5. 选中 16 位/HDR 图层（`图层 > 位深` 相关入口或效果层）按 `Backspace`/`Ctrl+X`：
   状态栏**明确拒绝**并说明原因，像素**不得**被降级或抹错区域。
6. 只选中一个轴对齐的 8 位像素层，`Ctrl+C` 后与源层做逐字节比较（可用
   `visual_check.py --scene clipboard` 作为快速回归）：必须完全一致。

**不该发生**：`Ctrl+C`/`Ctrl+V` 不应再触发裁剪/移动工具；`Backspace` 不应删除
图层；一次粘贴不应产生两个撤销步。

**自动化**：`visual_check.py --scene clipboard`（6 条断言：铺橙 → 拷 → 清 → 贴入 →
撤销 → 粘贴 → 撤销）。

## M47 关闭 / 退出的未保存提示（2026-10-22）

> 改动过的文档点窗口右上角叉（或 `文件 > 退出`）不再直接消失：右栏出现
> 「关闭文档（Close）」面板，动作行三选一 —— **保存并关闭** / **不保存，直接关闭** /
> **取消（留在文档）**，默认停在「保存并关闭」。`S` 保存并关闭、`D` 不保存、
> `Esc` 取消，`Tab`/↑↓ 或 ←/→ 换档、回车执行。**不是系统弹窗**（`MessageBox`）。

**准备**：`Ctrl+N` 新建，用形状工具画一块橙色（让文档变脏，标题栏出现 `*`）。

1. 点右上角叉：窗口**不得**关闭；右栏出现关闭面板，动作行高亮在「保存并关闭」。
   状态栏提示「关闭文档：S 保存并关闭 · D 不保存 · Esc 取消」。
2. 按 `Esc`：面板消失，窗口仍在，**画布像素与撤销栈都不变**；标题栏仍是脏标记。
3. 再点叉，按 `D`：窗口立即关闭，不退化成保存对话框。
4. 再点叉，按 `S`（未命名文档）：先弹另存为；**取消**另存为 → 面板关闭、
   窗口**仍在**，状态栏写「未保存（另存为已取消），窗口未关闭」；再点叉 → `S` →
   给个路径存下去 → 窗口关闭。
5. 对一个**已保存过**的文档（有路径）做一次修改，点叉后按 `S`：直接写回原路径并关闭，
   不弹另存为；重开文件能看到那次修改。
6. 提示开着时再点一次叉：等同取消（面板关闭、窗口留着），已选的那一档不被重置。
7. 未改动的新文档（标题无 `*`）点叉：**不出现**面板，直接关窗。

**不该发生**：`MessageBox` 之类阻塞式系统弹窗（自动化会被拖成超时）；「保存」路径上
另存为被取消却仍然关窗；取消后文档被改动；提示下方漏出工具快捷键（按 `V` 不应变成移动工具）。

**自动化**：`visual_check.py --scene close_prompt`（5 条断言：脏文档关窗后仍存活 →
右栏标题区像素变化 → `Esc` 后仍存活 → 取消不改画布 → 按 `D` 后 3 秒内退出）。


- 交互外壳主画布无直呈：走 `PrintWindow`/GDI 路径，`comp_render_document(kind=HWND)` 仍是 `UNSUPPORTED`；
  直呈能力经 `--present-bench` 独立窗口验证（D3D12 构建 + 合格文档才启用）。
- GPU 只覆盖子集，其余回退 CPU；GPU 慢于 CPU 属已知。
- 调整层只作用于下方内容（上游语义），挂在像素层上看不到变化不是 bug。
- 文字只支持 ASCII；CJK/富文本未接。
- 未实现：Select Subject / Remove Background / RAW 解码 / HEIC / WebP / SVG / PSB / TIFF。
- 自动化脚本会抢前台（`SetCapture` 需要），跑的时候别用键鼠；它不移动物理光标。
